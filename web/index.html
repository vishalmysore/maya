Maya: a yes/no gate in your browser

A 150M-parameter model that reads a text and answers yes/no questions about it, fully on your device (ONNX Runtime Web, int8, about 160 MB downloaded once). Every answer is yes, no or, if you set a band, not sure. Code and results.

Not loaded.

Both at 0.50 = strict yes/no. Widen the gap to get "not sure" in between. Thresholds with a guaranteed error rate have to be fitted on labeled examples of your own inputs (see the README).

Maya v0.1 is strongest on the kinds of text it was trained on (agent plans, moderation, support tickets, deliveries, email, IT incidents, reviews, expenses, meetings, code changes, insurance and sales). On unseen domains it is level with Laya, and it can be fooled by word overlap, so do not use it as the only safety check. Apache-2.0, unofficial experiment.
